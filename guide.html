2. 五個分頁說明

📡 BQB Bluetooth

比較 Allion、Dekra、TUV RH 三家實驗室的 Bluetooth 認證費用。
可複選項目：RF-PHY、Profile、Profile Check、BQC Review、RN/DID、Handling Fee。
表格最下方顯示各實驗室費用加總。

🛡️ Safety/Energy

比較 Wendell、Perfectlink、USS 三家的安規費用。
可複選 Region 和 Standard。
欄位：UL Cert/Rep. | TUV SUD Cert/Rep. | WD/USS for Test | UL Total | TUV Total

📡 EMC/RF

比較 TUV Rh vs TUV SUD 的 EMC/RF 費用（Camera Doorbell）。
可複選 Country/Region 和 Scope（EMC、RF、Telecom）。
表格最下方顯示 Total 及節省費用。

🌍 GMA with WiFi BLE

23 個國家的 WiFi/BLE 認證費用比較。
比較 UL、BV、CSA、Sporton、TUV、KIWA 六家實驗室。
可複選 Country、Mandatory Status、Lab，並可篩選 Recommended Lab。

💰 Cost Summary

彙整所有分頁中已選定的費用，提供完整費用總表。
在各分頁選定條件後，切換到此分頁點 Refresh Summary 查看各項目小計及 Grand Total。
綠色 ✓ = 最低總費用方案。

3. 顏色與符號說明

$1,200 ✓= 該行最低價格
$6,000= 該行最高價格
$1,930 ★= 該國家推薦實驗室（GMA）
Mandatory= 強制認證
Voluntary= 自願性認證
Not Mandatory= 非強制
💰 Total= 選定項目的費用加總列

4. 篩選功能說明

複選 Checkbox

BQB、Safety/Energy、EMC/RF、GMA 分頁都支援複選篩選：

  • 預設全選，可以任意勾選/取消
  • 全部取消 → 顯示空白（No data）
  • 選定後表格即時更新，不需要按確認

Safety/Energy 特別說明

  • 先選 Region（CB / EU / US/CA），Standard 清單會自動更新為該 Region 的法規
  • 再選 Standard 篩選特定法規

GMA 特別說明

  • Recommended Lab 下拉選單：篩選特定推薦實驗室的國家
  • Lab 複選：只顯示選定實驗室的費用欄位

5. 資料更新流程

Dashboard 資料來自 SharePoint，全程自動更新，不需要手動操作：

📊 新 Excel 上傳到 SharePoint
→
⏱ 自動偵測（5分鐘內）
→
🔄 自動解析 + 重建
→
🚀 自動推送 GitHub Pages
→
✅ 重新整理頁面即可
📁 Archive 資料夾內的 Excel 不會被讀取。
如需排除某份報價單，請將該 Excel 移到 SharePoint 的 Archive/ 子資料夾。

6. Excel 檔案命名規則

系統根據檔名自動判斷類型，請依照以下規則命名：

檔名格式對應分頁來源實驗室
BQB*Allion*.xlsxBQB BluetoothAllion
BQB*Dekra*.xlsxBQB BluetoothDekra
BQB*TUV*.xlsxBQB BluetoothTUV RH
EMC+RF*TUV Rh*.xlsxEMC/RFTUV Rh
EMC+RF*SUD*.xlsxEMC/RFTUV SUD
Safety*Wendell*.xlsxSafety/EnergyWendell
Safety*Perfectlink*.xlsxSafety/EnergyPerfectlink
Safety*USS*.xlsxSafety/EnergyUSS
GMA*.xlsx 或 *countries*.xlsxGMA with WiFi BLE—
⚠️ 檔名不符合規則的 Excel 會被系統跳過（顯示 [SKIP]）。

8. 常見問題

Q: 頁面顯示舊資料，如何更新？

按 Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）強制重新整理。

Q: 某個 Excel 的資料沒有出現？

確認檔名符合命名規則，且不在 Archive 資料夾內。查看 auto_update.log 確認是否有 [SKIP] 訊息。

Q: 費用顯示 N/A 是什麼意思？

該實驗室沒有提供該項目的報價，或該國家不適用。

Q: Cost Summary 沒有資料？

請先在各分頁選定條件，再切換到 Cost Summary 分頁點 Refresh Summary。
